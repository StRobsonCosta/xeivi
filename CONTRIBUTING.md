# Contributing

Thanks for contributing! Please follow these steps:

- Fork the repository and create a feature branch from `develop`.
- Run `mvn -B test` and `npm ci && npm test` (frontend) locally before opening a PR.
- Add tests for new features and include clear acceptance criteria in ClickUp tasks.
- Use semantic commit messages (e.g., `feat:`, `fix:`, `chore:`).

Pull requests should reference ClickUp task IDs and include a short checklist of work done.
